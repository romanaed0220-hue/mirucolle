# 导师/同学反馈与设计演变（时间线）

原始记录为语音转写（有识别错误），完整版见 `docs/source/`。这里只保留与 App 设计直接相关的要点。

## ① 進捗1（2026-06 末）——旧版「図鑑アプリ」被要求推倒重来
旧概念：日常里发现的东西做成「図鑑カード」，按用户自定的主题收集（四季的碎片、圆的东西等），理论背景是注意力恢复理论（ART: Being away / Fascination / Extent / Compatibility），有 HTML 原型（記録・収集・つながり三页，含限时挑战与卡片交流）。

反馈要点：
- 缺 **Reason Why**：为什么要来这个 App？有什么乐趣？
- 「図鑑」范围太宽：第 1/2/3 个用户会发什么？一个人发天空、另一个人发日本酒，没有交流理由。
- 与 Instagram/Pinterest/Google 图片区别不清。
- 奖励式挑战（"奖励越豪华越有人来"）不能产生自发使用动机。
- 同伴（不用 SNS 的人）的直白感想："看不懂做这个是为了什么。"
- 结论：**暂停做原型细节，用 7 月重新设计概念**，从"为什么会想到図鑑、真正想实现什么"回到原点。

## ② 進捗2（7 月中旬）——新概念：パレイドリア／見立て
- 出发点：刷 SNS 脑子累 → 看天空云像动物/脸 → 心情切换。
- 3 步：**撮る → なぞる → 名前をつける**；保存的只有手指描出的形。
- 他人在同一张照片上描出不同的形 → 看解释差异。
- 当时的三屏：記録 / 収集 / 発見（后来发展为「つながり」）。
- 导师反馈：方向好；类似案例是 お絵かきソー（同一块香草冰淇淋各人画不同的东西）。
  - 问题：设计默认了"用户会主动、会持续来"。要按"人不会来"的前提设计继续使用的机制。
  - 建议：运营方发布お題；定期比赛+奖项（**后被作者否决**，见原则文档）。
  - 要多调研相似案例（App 内外），把能"存活"的要素放进来。
- 同伴建议（采纳为后来的点数设计灵感）：按步行距离给积分、登录奖励、积分换笔色/印章。
- 行动：基于新概念**重建 HTML 原型**，加视觉设计，部署，5–10 人测试。

## ③ 進捗3（9 月上旬）——继续使用机制落地
已实现到设计里的新功能：
- チャレンジ机能（官方お題、参加得点、裏世界）
- 月間ピックアップ（无排名、无数字、特殊演出）
- 点数用途（笔色粗细 / 瓶子设计 / 主题色 / 补参加）

导师反馈：
1. App 还没名字（当时）→ 资料里写"今後決定"。**之后 9 月已定名为ミルコレ。**
2. **"SNS 疲劳"被 App 解决，存在逻辑跳跃**：在同一类 SNS/App 里真的能减轻疲劳吗？需要根据/事实支撑（这是调研任务，不是代码任务）。
3. 设计本身 OK，继续推进。
4. 目标：**11 月内全部完成（完パケ）**，实际提交 1 月。

## ④ 中間発表（2026-09-14）
- 関先生：
  - 「见る前に描く」需要主动想象力，对一部分人是负担（例如自己想"云像兔子"很难）。
  - 若由 **AI 来提示（サジェスト）**，也许更容易接受。（**仅为建议，作者尚未采纳**，见待定事项。）
  - "给 SNS 疲劳的人另一种消磨时间的方式"这个定位可以理解。
  - 指出：App 变大之后，会形成新的社交场，再次引发同样的 SNS 疲劳（困境）。
- 京極先生：
  - 评价中间发表质量高。
  - **继续使用性**是关键：用一次觉得"有趣"就结束怎么办？
  - 社交功能越扩展，越会产生"比较（他比我画得好/差）"，这是设计上的根本矛盾；**在设计前就意识到这点是好事**，希望在剩余时间里一起想解决方案。
- 行动项：
  1. 设计上解决"比较/竞争"的困境
  2. 通过用户调查检验继续使用性

## ⑤ 中間発表前后已落实的设计决定（来自 Project 内对话，用户已核对）
- App 名称定为**ミルコレ**（見る × コレクション）。
- 点数用途为 5 种（线条、瓶子、主题色、补参加、命名字体/文字装饰）；点数目前只能通过参加挑战获得。
- 补参加规则统一：没参加的期默认只能看不能画，用点数兑换后可限定次数补参加。
- 裏世界排列：自己的作品第一，其余随机，避免比较；裏世界里没有瓶子。
- 月間ピックアップ：不含お題照片；点开可看最初解读和当月所有参加者的解读；被描次数对投稿者也不显示、不通知。
- 収集页：只有形状浮动，无卡片框和照片背景；合集用玻璃瓶呈现，发表合集解锁新瓶子。
- 作者对"SNS 疲劳为什么能被缓解"的补强：把定位调整为"替代碎片时间里被动刷 SNS 的主动创作观察"，并引用了"失去主体感是 SNS 疲劳原因之一"的研究（Constantinides & Bowers, 2021；Pang et al., CHI 2025）和涂鸦减压研究。这些是学术材料，不是 App 功能。
